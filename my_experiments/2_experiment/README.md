# Second experiments

## Changes to first experiment
The small models I was testing were not outputting results in the required format. Although I intended to not use chat templates, evaluation was too hard to conduct. After small experiments with using chat templates, all models showed an improved output and better instruction following. Therefore, I rewrote all models and prompts to use chat templates.

Note that [Khodja et al. 2025](http://arxiv.org/abs/2502.01220) showed that chat templates were not always helpful for models and instruction following in a temporal benchmark proposed by them.
